# Cash Track

Personal application for tracking monthly income, expenses, and personal financial movement.

Stack: React Native + Expo + TypeScript (frontend), .NET / C# REST API (backend), Firebase Authentication (Google Sign-In) + Cloud Firestore (infrastructure). The API deploys to AWS Lambda via Terraform and GitHub Actions: see [infra/README.md](infra/README.md).

Full implementation document (architecture, domain model, dashboard, MVP scope, roadmap): [docs/cash-track-implementation.md](docs/cash-track-implementation.md)
