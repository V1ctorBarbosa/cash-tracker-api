# Cash Track

Personal application for tracking monthly income, expenses, and personal financial movement.

Stack: React Native + Expo + TypeScript (frontend), .NET / C# REST API (backend), Firebase Authentication (Google Sign-In) + Cloud Firestore (infrastructure). AWS via Terraform is planned for after the application is validated locally.

Full implementation document (architecture, domain model, dashboard, MVP scope, roadmap): [docs/cash-track-implementation.md](docs/cash-track-implementation.md)
